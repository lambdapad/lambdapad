Quickstart

One config file, one command

Define your sources, pages, and assets in lambdapad.exs and preview locally with lpad http.

lambdapad.exs
import Lambdapad

blog do
  source(posts: "posts/**/*.md")

  pages "posts" do
    set(from: :posts)
    set(uri: "/blog/{{ post.id }}")
    set(var_name: "post")
    set(template: "post.html")
  end

  assets "css" do
    set(from: "assets/**/*.css")
    set(to: "site/")
    set(tool: :tailwind)
  end
end
Terminal
# Create a new site
$ lpad new my-site
$ cd my-site

# Build static HTML & assets
$ lpad

# Preview locally at http://localhost:8080
$ lpad http
